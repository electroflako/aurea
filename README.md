# AUREA – Joseba Burusko: Escultura y obra portátil

E-commerce completo y funcional para una tienda de joyería y escultura artesanal:
landing editorial, catálogo con filtros por URL, fichas de producto, carrito persistente,
checkout simulado en base de datos, panel de administración (/admin) y newsletter bilingüe (Castellano y Euskera).

## Stack
- **Next.js 16** (App Router, Server Components)
- **React 19** + **TypeScript**
- **Tailwind CSS 4**
- **PostgreSQL + Drizzle ORM**
- **Lucide React**

## Despliegue en Vercel
1. Conecta este repositorio en [Vercel](https://vercel.com).
2. Configura una base de datos PostgreSQL gratuita en Neon o Supabase.
3. Añade la variable `DATABASE_URL` y despliega con un clic.
